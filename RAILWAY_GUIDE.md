# Инструкция по деплою на Railway

Этот проект полностью готов к развертыванию на Railway. Следуйте этим шагам:

## 1. Подготовка в Railway
1. Создайте новый проект в Railway.
2. Выберите **Deploy from GitHub repo** и выберите ваш репозиторий.
3. Добавьте базу данных **PostgreSQL** в проект Railway.

## 2. Настройки (Variables)
Добавьте следующие переменные окружения в разделе **Variables**:

- `DATABASE_URL`: (Railway заполнит автоматически, если добавить плагин PostgreSQL)
- `TELEGRAM_BOT_TOKEN`: Токен вашего бота от @BotFather
- `TELEGRAM_CHAT_ID`: Ваш ID чата (или ID группы)
- `NODE_ENV`: `production`

## 3. Команды сборки и запуска
Railway должен автоматически определить настройки из `package.json`, но если потребуется ввести вручную:

- **Build Command**: `npm run build`
- **Start Command**: `npm start`

## 4. Порт
Проект слушает порт, указанный в переменной `PORT` (по умолчанию Railway выставляет его сам). В коде сервера используется `process.env.PORT || 5000`.

---
**Готово!** После настройки переменных Railway сам соберет проект и запустит его.
